## 🌟 全版本核心功能与版本演进 (Version Features)

### 🌈 Version 1.1 - 稳健防误删、深度社区剪藏、网盘流式分块与桌面端发布

#### 1. 🛡️ 防误删更安心：同名笔记极简安全清理交互
- **默认红色主要选项，杜绝误伤**：同名清理弹窗中将“仅将当前选中文档移入废纸篓”设为默认主操作，其他同名副本 100% 完好无损，杜绝误伤其他副本；
- **批量移入废纸篓直达，自带一键撤销**：彻底精简多余确认弹窗，“全部移入废纸篓”点击即直达，底部配有 5 秒可点击的「撤销恢复」按钮，手误秒级还原；
- **舒适大卡片尺寸，贴合触控直觉**：选项全面升级为 40 像素标准大卡片，边距宽裕自然；编辑器顶部删除图标更名为「移到废纸篓」，让删除透明可预期。

#### 2. 🌐 网页剪藏全面进阶：论坛全楼层一网打尽，图片自动安全离线
- **论坛全楼层讨论完整捕获**：针对 LINUX DO 等各大主流技术论坛社区深度适配，点击剪藏按钮，自动将当前网页视口内加载的楼主主贴与所有参与讨论的楼层内容整齐捕获并导入笔记；
- **右键深度摘要，完整保留长文主贴**：右键“摘要网页内容”彻底解除字数截断限制，完整提取主贴全部多级小节、代码块与高清配图，自动过滤无关评论杂音；
- **剪藏后全自动离线远程图片**：每次剪藏网页内容后，系统自动在后台执行远程资源一键离线，将所有网络图片秒级下载并安全存入本地，告别原帖删图、图床失效与防盗链拦截。

#### 3. 🎨 Notion 属性内聚工作台与状态栏精炼
- **属性紧凑并排，操作更顺手**：顶部操作栏右侧整合：目录与分类紧凑并列，修改路径与标签不再需要大幅度横移鼠标；最后一列独立放置“转为书籍专栏”入口，认知明确；
- **底部状态栏极简呼吸设计**：隐去重复标题，以轻量呼吸风格专注于实时字数统计、编辑保存状态与网络就绪情况，守护沉浸无扰的写作环境。

#### 4. ☁️ 百度网盘超大文件 4MB 分块稳定同步与状态自愈
- **4MB 流式切片，杜绝大文件超时**：全新重构网盘同步引擎，长篇电子书、长笔记与大体积附件自动按 4MB 边界进行智能切片上传，接入 Precreate 预校验与最终合成，彻底杜绝超时失败；
- **状态机中断自愈与断点恢复**：网络波动导致同步中断时，状态机自动安全回滚并支持断点自愈，确保本地沙箱与云端完全一致。

#### 5. ⚡ 标题输入性能飞跃与智能短名
- **打字彻底消除延迟**：标题输入框重构为局部微观状态，连续打字不再频繁触发大文章渲染与磁盘写入；
- **敲击回车一键跳入正文**：在标题处敲击回车，系统自动保存标题并瞬间将光标引导至正文首行，创作行云流水；
- **英文短名智能消歧**：重名笔记自动追加序号平滑化解全路径重合，普通日常随手记 100% 保护 AI 额度，零浪费 Token。

#### 6. 🤖 AI 智能创作大进化：一键生成自动收起，停止操作一目了然
- **创作生成自动收起**：点击执行创作生成后，微调卡片立即自动收起，正文区域完整展现打字机式流式生成；
- **生成过程一键中止**：AI 正在生成时若再次展开面板，按钮自动反转为醒目的红色「■ 停止生成」，点击即刻停止；
- **史诗与传奇超长篇幅支持**：支持 5000 字以上史诗长篇与 8000 字以上传奇长文分小节结构化推进；提供“默认自然、通俗生动、理工严谨、商务公文、优美文学、幽默风趣”等 6 种文风基调。

### 🏛️ Version 1.0 - 核心写作基石、离线图表转译与多端发布

#### 1. ✍️ 极致纯粹的沉浸式 Markdown 创作
- **所见即所得编辑器**：实时渲染 Markdown 语法，代码高亮、表格、列表、任务项开箱即用；
- **Markdown 标题拷入智能净化**：从外部网页或文档复制标题时，自动剥离前导 `#`、行内反引号、加粗等排版噪声，光标智能定位末尾；
- **KaTeX 数学公式原生排版保真**：全层级自然块级流排版，支持矩阵 (Matrix)、分段函数 (Cases)、高阶积分上下标完美渲染，零遮挡零截断。

#### 2. 📊 纯前端离线 PlantUML 转 Mermaid 智能转译引擎
- **零外部服务依赖**：无需搭建 Java PlantUML 服务器，纯前端秒级转译；
- **全语法深度适配**：完整支持时序图 (Sequence Diagram) 别名重映射、用例图 (Use Case Diagram) 边界容器与胶囊节点；
- **双模预览与高清导出**：代码块支持 Code / Preview 双模平移缩放、全屏大图灯箱及无损 SVG / 2x 高清 PNG 导出。

#### 3. 🚀 Git 远程博客一键直发
- **多平台 Git 仓库推送**：支持将文章直连推送至 GitHub、Azure DevOps 等代码仓库，一键构建静态博客；
- **生命周期状态追踪**：精准标注“未发布”、“已发布”、“待更新”，远端一致性自动探测自愈。

#### 4. 📚 专栏长篇与电子书 EPUB 汇编导出
- **专栏汇编成书**：将日常积累的系列文章一键编排为章节目录；
- **标准 EPUB 3.0 / Markdown 打包**：内置专业封面设计与排版模板，一键导出可在各类电子阅读器中流畅阅读的标准电子书。

#### 5. 🛡️ 存储指纹去重与双通道网络代理
- **OPFS 媒体指纹去重**：SHA-256 二进制哈希智能去重，自动探测悬空引用并平滑重定向；
- **双通道网络下载代理**：跨域或防盗链资源自动走 Background Service Worker 特权代理下载，保持控制台零错误；
- **RFC 9562 UUID v7 单调主键**：消除 IndexedDB 大批量插入写放大，纯前端逆解毫秒时间戳。
